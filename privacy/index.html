개인정보 안내

커뮤랭크는 현재 별도의 회원가입을 요구하지 않으며, 개인화 기능은 가능한 한 사용자의 브라우저 안에서 처리합니다.

현재 저장되는 정보

‘내 관심’에서 저장한 관심 키워드·커뮤니티, 최근 본 게시글 등은 브라우저의 로컬 저장소(localStorage)에 보관될 수 있습니다. 이 정보는 현재 커뮤랭크 서버의 회원 계정에 연결해 저장하지 않습니다.

방문자 분석

현재 저장소의 중앙 방문자 분석 설정은 비활성화 상태입니다. 향후 방문자 분석 도구를 활성화하는 경우 이 안내를 갱신하고 필요한 범위에서 데이터 처리 내용을 명시합니다.

광고

현재 커뮤랭크에는 Google AdSense 광고가 활성화되어 있지 않습니다. 향후 광고 서비스를 활성화하는 경우 광고 제공 과정에서 사용되는 쿠키·식별자·동의 절차 등 필요한 개인정보 처리 내용을 이 페이지에 반영합니다.

외부 사이트 이동

‘원문 보기’를 선택하면 각 커뮤니티 사이트로 이동합니다. 이동 이후의 개인정보 처리와 쿠키 정책은 해당 사이트의 정책이 적용됩니다.

브라우저 데이터 삭제

관심 설정은 ‘내 관심’ 화면에서 삭제할 수 있으며, 브라우저의 사이트 데이터 삭제 기능을 이용하면 커뮤랭크가 로컬 저장소에 보관한 정보도 함께 지울 수 있습니다.
