# 커뮤랭크 (COMMURANK)

<https://commurank.kr>

대한민국 주요 커뮤니티의 인기글을 실시간·일간·주간·월간으로 모아보는 통합 랭킹 서비스입니다.

## 현재 구현
- 커스텀 도메인 `commurank.kr` + GitHub Pages HTTPS
- 약 15분 간격 자동 수집 + freshness watchdog
- 실시간 / 급상승 / 일간 / 주간 / 월간 TOP100
- 사이트별 전용 랭킹
- 카테고리·커뮤니티·키워드 필터
- 순위 상승 / 하락 / NEW 표시
- 일간·주간·월간 과거 아카이브
- 크로스 커뮤니티 동시 화제 및 이슈 TOP20
- 오늘의 인터넷 브리핑
- 게시글 상세 분석 / 통합 검색 / 내 관심 피드
- 다크 모드 / PWA / 모바일 반응형
- 운영 대시보드 및 데이터 신선도 점검

## 수집 대상
디시인사이드, 에펨코리아, 더쿠, 루리웹, 클리앙, 인벤, 뽐뿌를 대상으로 공개 인기글 메타데이터를 수집합니다.

사이트별 접근 제한이 발생하면 최근 정상 수집 캐시를 사용하며, 캐시도 없으면 해당 소스는 “수집 점검 중”으로 표시합니다. 에펨코리아는 외부 자동 요청에 대한 제한이 간헐적으로 발생할 수 있습니다.

## 운영 원칙
- 게시글 본문 전체를 복제하지 않고 제목·반응 지표·원문 링크 중심으로 제공합니다.
- 원문 저작권은 원 작성자 및 각 커뮤니티에 있습니다.
- 랭킹 점수는 각 커뮤니티 내부 반응을 정규화한 뒤 통합합니다.
