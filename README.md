# 커뮤랭크 (COMMURANK)

대한민국 주요 커뮤니티의 인기글을 실시간·일간·주간·월간으로 모아보는 랭킹 서비스 MVP입니다.

## 현재 구현
- 실시간 / 일간 / 주간 / 월간 탭
- 카테고리 필터
- 커뮤니티별 필터
- 통합 인기글 랭킹 UI
- 순위 상승 / 하락 / NEW 표시
- 커뮤니티 랭킹
- 크로스 커뮤니티 동시 화제 카드
- 다크 모드
- 모바일 반응형

## 다음 단계
1. 실제 사이트별 수집기 연결
2. 서버/DB 분리 (Supabase/PostgreSQL)
3. ranking_snapshots 저장
4. 과거 일간·주간·월간 TOP100 아카이브
5. 중복 이슈 클러스터링
6. 커뮤니티 반응 비교/AI 요약

> 현재 GitHub Pages용 정적 MVP이며, 실제 수집 기능은 서버 환경(Vercel/Supabase 또는 별도 worker)을 연결한 뒤 활성화합니다.
