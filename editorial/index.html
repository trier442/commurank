EDITORIAL & DATA PRINCIPLES

편집·데이터 원칙

커뮤랭크는 외부 게시글을 다시 쓰는 매체가 아니라, 공개 인기글 목록과 반응 지표를 정리해 인터넷의 관심 흐름을 보여 주는 데이터 서비스입니다.

출처와 원문을 우선합니다

각 게시글은 출처 커뮤니티와 원문 링크를 함께 표시합니다. 게시글 제목을 누르면 원문으로 바로 이동하며, 커뮤랭크가 원문의 작성자나 게시 주체인 것처럼 표시하지 않습니다.

본문 전체를 복제하지 않고 랭킹·트렌드 분석에 필요한 제목과 공개 반응 지표를 중심으로 다룹니다.

자동화되는 영역

수집, 중복 정리, 카테고리 분류, 키워드 추출, 이슈 묶기, 랭킹 계산, 일간·주간·월간 데이터 요약은 자동화된 규칙으로 처리됩니다.

자동 분류는 문맥을 완벽하게 이해하는 사람이 직접 편집하는 방식과 다르므로 오분류나 과도한 묶음이 발생할 수 있습니다. 명백한 오류가 확인되면 규칙을 수정합니다.

사실 판정과 의견을 대신하지 않습니다

커뮤랭크에서 ‘화제’, ‘급상승’, ‘상위 이슈’라고 표시되는 것은 특정 주제가 수집 대상 인기글에서 많이 또는 빠르게 포착됐다는 의미입니다. 게시글 내용의 사실 여부, 가치 판단, 찬반 또는 사회 전체의 여론을 뜻하지 않습니다.

리포트는 데이터 요약입니다

일간 브리핑과 주간·월간 트렌드 리포트는 해당 기간에 수집된 공개 인기글 메타데이터를 바탕으로 작성합니다. 집계 기간이 짧거나 데이터가 부족하면 ‘집계 중’ 또는 ‘부분 집계’라고 표시해 완전한 기간 통계처럼 보이지 않도록 합니다.

정정과 제외

원문이 삭제되거나 접근할 수 없게 된 경우 이후 수집에서 제외될 수 있습니다. 수집 구조 변경, 중복 판정, 카테고리 오분류처럼 서비스 자체에서 발생한 오류는 확인 후 수집·분류 규칙에 반영합니다.
